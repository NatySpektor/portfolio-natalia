PORTFÓLIO - NATÁLIA SPEKTOR

Projeto acadêmico desenvolvido com base no template Start Bootstrap Resume.

TECNOLOGIAS
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

COMO ABRIR
1. Extraia a pasta do ZIP.
2. Abra o arquivo index.html no navegador.
3. É recomendado estar conectado à internet para carregar Bootstrap, Bootstrap Icons e as fontes externas.

ESTRUTURA
index.html        -> estrutura e conteúdo da página
css/styles.css    -> estilos e responsividade
js/scripts.js     -> interações em JavaScript
assets/img/       -> foto de perfil

INTERAÇÕES EM JAVASCRIPT
- Menu lateral responsivo
- Destaque da seção atual no menu
- Animações ao rolar a página
- Barras de habilidades animadas
- Botão voltar ao topo
- Modo claro/escuro com preferência salva
